# פרומפטים ליצירת תמונות — דפי הנחיתה

**הוראות שימוש:**
1. כל פרומפט כאן כתוב באנגלית (כלי AI עובדים טוב יותר באנגלית).
2. **שמות הקבצים מוגדרים מראש** — שמרו את התמונות בדיוק עם השם והנתיב המצוינים. הקוד כבר מצפה להן.
3. **יחס מימדים מוגדר לכל תמונה** — יש לכבד אותו אחרת תהיה חיתוך.
4. **סגנון אחיד**: כולן צריכות להיות עם פלטה דומה לדומיין הראשי — כהה, מינימליסטי, אלגנטי, גרעיני (cinematic), עם נגיעות זהב/ציאן/אמרלד.
5. **לאחר היצירה**: שמרו את הקבצים ב-`public/images/landing-assets/` (התיקייה צריכה להיווצר). הדפים יציגו את התמונות אוטומטית.
6. **פורמט מועדף**: WebP או JPG, איכות 85-90%, משקל מתחת ל-300KB לכל תמונה.

## כלי AI מומלצים

- **DALL·E 3** (ChatGPT Plus / API) — מצוין לתמונות מציאותיות והדמיות מקצועיות
- **Midjourney v6+** — הכי איכותי לתמונות סינמטיות ופורטרטים
- **Flux 1.1 Pro** (Replicate / fal.ai) — מהיר ונקי, מצוין לאיורים שקופים PNG
- **Adobe Firefly** — לתמונות מסחריות עם זכויות מסחריות מובטחות

**טיפ לפורטרטים:** בקשו "**Israeli**" כדי לקבל מראה אותנטי לקהל המקומי.
**טיפ לעקביות:** לפני שיוצרים, צרו תמונת רפרנס אחת ובכל פרומפט הבא תוסיפו "**in the same style as reference**".
